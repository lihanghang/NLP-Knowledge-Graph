# PDF.js Generic Viewer

This directory vendors the browser-ready files from the official Mozilla
PDF.js v6.3.289 distribution:

https://github.com/mozilla/pdf.js/releases/tag/v6.3.289

Source maps, the sample PDF, and unused translations are omitted. The site
adds web/nlpkg-viewer.mjs and one script tag in web/viewer.html so binary
.pdf.bin assets keep their original .pdf filename when downloaded.
